LEFT BOTで You (1P) を選ぶと自分で対戦できます。操作は ← → 移動、↓ ソフトドロップ、Space ハードドロップ、Z/X 回転、A 180度回転、C ホールド、Esc リセット。キー割り当てと操作感（DAS・ARR・DCD・SDF）は SETTINGS で変更できます。自然落下はなく、ハードドロップした時点がそのミノの着地時刻になるので、置くのが遅いほど自分のPPSが下がります。

START MATCH で対局が始まります。もう一度押すと一時停止、さらに押すと再開します。左右のBotは1つの共通クロックで進み、SEED が同じなら同じ対局を何度でも再現できます。Botごとの探索条件は各 SETTINGS で設定します。SELECTION（探索数）と THINK TIME（探索時間）は少なくとも一方をONにする必要があり、先に達した方で探索を打ち切ります。THINK TIME は端末やブラウザの状態で結果が変わるため、既定はOFFです。PPS をOFFにすると、探索が終わり次第すぐ置きます。FAIR COMPARISON をONにすると、CC2系のBotを SELECTION 512・1 PPS に揃え、同じタイミングの探索を順番に実行して条件差をなくします。保存した個別設定は上書きされず、OFFに戻すと元に戻ります。対局が1手でも進むと EXPORT の SAVE .json でこの対局の記録を保存できます。
