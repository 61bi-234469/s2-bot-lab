使い方

このアプリについて

Botが決めるのは「どこに置くか」だけです。ライン消去・攻撃・B2B・COMBO・相殺・せり上がりの判定は、すべてTETR.IO Season 2 のルールを再現したSimulatorが行います。回転やキックの入力手順そのものは再現していないため、スピン判定の一部はSimulator側の独自判定に依存します。

SINGLE ANALYSIS（1手解析）

ANALYSIS BOTを選び「THINK」を押すと、その局面での1手を提案します。「CANDIDATES」で複数の候補手を一覧表示でき、クリックすると盤面プレビューが切り替わり、「APPLY」で確定します。「AUTOPLAY」は提案の適用を繰り返し、「RESET」で盤面を初期化します。候補の数値はSimulatorで検証済みのものだけが表示され、検証できなかった候補は理由付きで選べません。Raw CC2とchouhy forkは実際に指す1手しか返さないため、候補は1行だけになります。

BOT vs BOT / 1P（対戦）

LEFT BOTとRIGHT BOTを選び、START MATCHで対局を開始します。もう一度押すと一時停止、さらに押すと再開します。STEPで1手だけ進めることもできます。LEFT BOTで「You (1P)」を選ぶと自分でプレイできます（← → 移動、↓ ソフトドロップ、Space ハードドロップ、Z/X 回転、A 180度回転、C ホールド、Esc リセット）。キー割り当てや操作感（DAS・ARR・DCD・SDF）はSETTINGSから変更できます。

実行方式は2つあります。TTRM INPUT（既定でON）は実際の入力と経過時間で進み、対局後に .ttrm として保存できます。OFFにすると固定探索モードになり、同じSEEDで再現できる .json として保存できます。TTRM INPUTで使えるBotの組み合わせは限られており、使えないBotはLEFT/RIGHT BOTの一覧でグレーアウトします。

MATCH SETTINGSでは、対局条件（SEED・MAX TURNS・FIRST TOなど）を設定します。LEFT BOTで「You (1P)」を選んだあとのSETTINGSには、HANDLING / 操作とMATCH RULES / 対局ルールがあり、TURN MATCH・1P INITIAL GARBAGE・STALL PENALTYなどを設定できます。各Botの探索条件（SELECTION・THINK TIME・PPSなど）はBotごとのSETTINGSボタンから設定します。

REPLAY（リプレイ再生）

.ttrmまたは.jsonファイルを読み込むと、記録された対局をそのまま再生できます。PLAYで再生・一時停止、◀◀ / ▶▶ で手番送り、SPEEDで再生速度を変更できます。タイムライン下のマーカーは赤＝せり上がったガベージ、緑＝相殺したガベージです。表示されるガベージの数値は再生から計算した値で、TETR.IOの集計値そのものではありません。
