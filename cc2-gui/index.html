LEFT/RIGHT BOTのどちらかに You (1P) を選ぶと自分で対戦できます。既定の操作は ← → 移動、↓ ソフトドロップ、Space ハードドロップ、Z/X 回転、A 180度回転、C HOLD、Esc リセット。DAS・ARR・DCD・SDF とキー割り当ては SETTINGS で変更できます。自然落下はありません。ハードドロップした瞬間の共有クロックがそのミノのロック時刻になるので、置くのが遅いほど自分のPPSが下がります。

START MATCH begins the series; pressing the same button again pauses it, and once more resumes. Both bots share one game clock. THINK TIME PACE derives each CC2 bot's PPS from its configured THINK TIME (1000 ms = 1 PPS) and gives that full time to the search. FAIR COMPARISON instead fixes both bots at 1 PPS and runs simultaneous searches serially to avoid direct CPU contention; it cannot be combined with THINK TIME PACE. Bot-specific parameters are configured independently from each SETTINGS button. QUEUE MODEL is a match setting, not an output one: TTRM QUEUE generates pieces with the 7-bag randomiser and, for non-simple bots, uses the deterministic no-HOLD input controller so each lock can be emitted as a verified TETR.IO input log. Therefore a TTRM QUEUE match is replay-compatible rather than a byte-for-byte CC2 final-placement match. EXPORT becomes available once a round has advanced — SAVE .json writes this engine's own match record, and SAVE .ttrm writes a server-verified TETR.IO replay.
